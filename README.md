Renders 19 November 2026 as one newspaper front page: 39 verified stories from every continent, drawn by a small Node program.

The image is a front page for Thursday 19 November 2026: the Shenzhen summit,
the ICJ's 9-6 genocide ruling, COP31's weakened draft, Anthropic's Nasdaq debut,
GTA VI's launch, the Riyadh strike and the Crimean bridge, then eight cards and
twenty-one ticker lines. `entry.png` is the entry; `design/front-page.html` is
the layout it was rendered from.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
